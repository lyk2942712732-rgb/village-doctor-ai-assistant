## 视觉设计

2026-10-12 按项目所有者要求，改为“村医工作簿”的文档工具视觉，参考 [StyleKit Notion 风格](https://www.stylekit.top/zh/styles/notion-style)。参考页已读取，主要采用米白背景、深灰文字、小圆角、细边框、系统字体、线性图标与低幅度点击反馈。

- 色彩：纸面 #F7F6F3、正文 #37352F、表单 #FFFFFF、说明 #706F6B、分隔 #E7E5E0、差异/错误 #B6433C。橙色和绿色仅用于有含义的状态。
- 字体：设备系统字体栈，中文 PingFang SC / Microsoft YaHei；标题 52rpx、正文 28rpx、标签 26rpx、说明 24rpx。全程本地字体与本地图标。
- 布局：首页按工作簿属性、接诊入口、待办表与工作目录排列；居民档案采用按行列表与历次就诊文档；统计采用本期台账与各村汇总；病历保留手填表单，AI候选位于各项下方。
- 结构：圆角控制在 4–8rpx；去掉大面积绿色、渐变、旋转图案与阴影。按钮和列表仅用浅灰背景反馈，无位移或缩放动画。不为手机端添加无法使用的拖拽把手。
- 图标：12个由代码绘制的线性图标；SVG为可编辑源文件，PNG用于微信原生图片组件。生成脚本为 scripts/draw-ui-icons.py。
- 业务交互：手填与AI填写并列、请求前提醒、逐项采用与红色差异标记保持原流程；图标和样式不改变云端权限或病历审核规则。

## 病历模板依据
按 [国家卫健委《病历书写基本规范》](https://www.nhc.gov.cn/wjw/gfxwj/201002/79d42b9c8b3f47ee91000d31de116784.shtml) 中门诊记录的核心字段组织：就诊时间、主诉、现病史、既往史、体格检查、辅助检查、诊断、处理意见和医师记录；另提供过敏史及随访计划。
这是辅助整理模板，未声称系统已通过电子病历合规或医疗机构认证。

## AI 与语音
通过云函数调用所配置的 HTTPS OpenAI 兼容 Chat Completions 接口：
- [腾讯 TokenHub 混元调用指南](https://cloud.tencent.com/document/product/1823/132252)。
- [混元兼容 API 示例](https://cloud.tencent.com/document/product/1729/111007)。
- [腾讯云录音文件识别](https://cloud.tencent.com/document/api/1093/37823)，使用 CreateRecTask + DescribeTaskStatus。
- [DeepSeek 官方 API](https://api-docs.deepseek.com/) 与 [Chat Completions 参数](https://api-docs.deepseek.com/api/create-chat-completion/)：已接入云端，使用当前 Flash 模型、JSON 输出及关闭思考的事实整理请求。
- [腾讯面对面翻译小程序](https://github.com/Tencent/Face2FaceTranslator)：微信同声传译插件提供另一种语音识别路径，需要先在公众平台添加插件。当前项目使用腾讯云 ASR，凭证已在云端配置并通过真实转写及手机录音验收；没有在缺少插件授权时声明同声传译插件可用。
AI 只整理原文，不添加诊断、处方、正常体征或“无过敏史”。模型输出仍需医师逐项核实。
