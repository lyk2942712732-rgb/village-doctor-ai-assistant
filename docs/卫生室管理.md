# 卫生室与团队管理

## 登录与工作卫生室
微信身份登录与加入卫生室分开。登录时医师姓名及邀请码可选；填写有效邀请码会自动加入，错误邀请码只提示加入失败，登录仍成功。未加入卫生室可完善姓名、创建或加入机构，不能接诊、读写居民档案或调用诊疗功能。

一个微信账号可加入多个卫生室。进入“我的卫生室”选择当前工作机构，之后居民、病历、名单、专家服务及统计均按该 clinicId 隔离。切换会清除列表页旧数据，旧页面尚未完成的请求不能写入另一个机构。原 hlj-clinic-001 和已有资料归属保持不变，旧 doctors 账号在登录时迁移为 memberships 结构。

## 地区与机构资料
卫生室名称、联系人、电话及详细地址可输入。所在地区使用省→市→区县→乡镇/街道→村/社区五级选择，上级改变会清空下级与服务村选择；服务村在所选乡镇范围内勾选，不选时以卫生室所在村为准。保存时服务器校验完整编码链并使用目录名称，防止不同地区混搭。旧机构没有地区编码时，需要负责人首次补选后才能保存机构资料；既有病历仍可访问。

目录来自 [Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)，WTFPL 许可，覆盖大陆31个省级地区，数据截止2023-06-30。上游已停止更新，因此近期更名、合并、调整的地区需要管理员更新目录。代码不杜撰下级村庄，也不把该目录标记为实时行政区划。可用 scripts/build-regions.py 重新生成云端分省压缩目录，更新数据来源时也应更新 regions.version 与来源说明。目录由云函数逐级返回，不增加前端主包体积。

## 创建、加入与成员管理
先登录，打开“我的卫生室”创建机构，填写负责人真实姓名和机构资料。创建请求有幂等编号，重试不会重复建档。负责人生成限时限次邀请码（1–30天、1–100人），完整码只在生成时显示，离开页面清除；数据库保存哈希及尾号，不保存明文。

普通成员可以主动退出，也可重新凭有效邀请码加入。负责人可以移除本室成员、停用邀请码、移交负责人和解散本室。移除或退出只影响本室成员关系，其他卫生室不受影响。负责人不能直接退出，需要先移交权限或解散。解散需再次确认机构名称，关闭所有成员访问且不允许新成员加入；历史档案保留，不能在小程序中恢复或物理删除。

移交同时修改机构负责人及双方本室角色；移出成员与机构解散后，服务器每次请求都会拒绝旧登录会话继续访问。归档病历、专家记录和导出前再次校验权限。私有 clinics/doctors/invitations 及诊疗表全部仅管理端可读写，界面隐藏按钮不是权限边界。

## 成员绩效与工作量
本室成员可按日期查看当前成员：归档病历数、去重接诊居民数、已生成转诊资料包数、专家意见记录数和其中随访数。病历按归档时间，资料包和服务记录按生成/录入时间统计，仅计本室数据。重复生成的转诊包会分别计数；不把草稿、失败导出计入工作量，不作为医疗质量评分。已退出成员的原始署名和诊疗台账保留。
